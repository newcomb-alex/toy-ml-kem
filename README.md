# toy-ml-kem
A toy project for the post-quantum cryptography algorithm ML-KEM.

# How to Run
This project only users standard python libraries. No dependencies are required to be installed to run the program. Therefore, an environment is not required. Requires Python 3.10+.

Run the test_mlkem.py script directly from the main project directory by running "python .\src\test_mlkem.py" within powershell or command prompt. 
 
To change the parameters, edit the parameters in params.py.
